# EL CHICANO — CINEMATIC DIGITAL EXPERIENCE 🌵🔥

Reconstrução autêntica e de alta fidelidade do portal oficial [El Chicano Mexican Food](https://elchicano.com.br/), combinando fidelidade visual e funcional absoluta com uma direção de arte cinematográfica, performática e imersiva.

---

## 🌟 Destaques da Experiência Cinematográfica

1. **Preloader Atmosférico:**
   - Abertura com badge da marca, micro-partículas âmbar em ascensão e barra de carregamento progressivo com o lema *"Feito com fé, fogo e coração"*.
2. **Hero Section com Canvas de Brasas:**
   - Motor de partículas de fogo em HTML5 Canvas (`FireCanvas`), fundo Ken-Burns, selo circular giratório animado (`• ORIGEM LITORÂNEA • ALMA MEXICANA • RANGO DE VERDADE`), selos *"TEX·BRA·MEX ®"* e *"Autêntico!"*.
   - Botões com neobrutalismo e sombras duras (`PEÇA AGORA` e `Nossa História`).
   - Card 9:16 com preview de preparo artesanal.
3. **Navegação Flutuante Responsiva (`Header`):**
   - Barra em formato pill flutuante com blur glassmorphism, logo SVG, links com indicador deslizante e menu mobile full-screen.
4. **Nossa História & Player de Vídeo Customizado:**
   - Seção editorial com os 3 pilares (*100% Artesanal*, *Fé & Coração*, *2 Cidades*).
   - Player de vídeo cinematográfico com controles customizados (Play/Pause, Mute/Unmute, Timeline Scrubber, Tempo corrido e Tela cheia).
5. **Cardápio Completo Interativo (74 Pratos Reais):**
   - 12 categorias oficiais (Combos, Burritos, Burrito Bowl, Tacos, Quesadillas, Veggie, Antojitos, Salsas, Sobremesas, Sucos, Bebidas e Cervejas).
   - Busca em tempo real com debounce e filtro por categorias.
   - Modal detalhado de prato com foto em alta resolução, ingredientes, picância e link direto para CardápioWeb.
6. **Mural e Galeria da Casa com Lightbox:**
   - Filtro por Tudo / Vídeos / Fotos.
   - Contador de likes interativo com animação de pulso.
   - Lightbox modal com reprodução de vídeo e navegação por teclado (Setas e ESC).
7. **Nossas Casas (Unidades Laguna e Florianópolis):**
   - Endereços completos, telefones, horários de funcionamento, botões de rota no Google Maps e WhatsApp direto.
8. **Franquias & Expansão:**
   - Apresentação do modelo de franquia com mural Frida Kahlo e modal interativo para captação de novos franqueados.
9. **Contato & Rodapé Institucional:**
   - Cards táteis com links para WhatsApp Floripa, Cardápio Online e Instagram oficial.
   - Rodapé com créditos, horários, citações da marca e copyright.
10. **Dock de Ações Rápidas Flutuante:**
    - Botão WhatsApp com radar verde pulsante, botão CardápioWeb e botão inteligente de voltar ao topo.

## 🛠️ Stack Tecnológica

- **Framework:** React 19 + TypeScript + Vite 6
- **Estilização:** Tailwind CSS v4 + Design Tokens Semânticos HSL/Hex
- **Efeitos e Animações:** HTML5 Canvas (3 motores dedicados: *Brasas de Fogo*, *Partículas Oceânicas Turquesa*, *Poeira Âmbar*), CSS Ken Burns e Neobrutalismo Tátil
- **Tipografia:** Lilita One (Display/Títulos), Sora (Corpo/Interface), Caveat (Caligrafia/Afeto), Outfit
- **Ícones:** Lucide React + SVGs Oficiais

## 🚀 Como Executar Localmente

### 1. Pré-requisitos
- Node.js (v18+)
- npm (v9+)

### 2. Instalação e Execução
```bash
# Acesse o diretório do projeto
cd "C:\Users\ricop\Documents\El Chicano"

# Instale as dependências (já instaladas)
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O servidor abrirá em: `http://localhost:3000`

### 3. Build de Produção
```bash
# Compilar bundle otimizado
npm run build

# Pré-visualizar o build localmente
npm run preview
```
